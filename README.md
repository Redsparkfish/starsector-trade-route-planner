# Trade Route Planner

一个为 Starsector 提供自动跑商路线规划的模组。

不想再一个个市场查价格、算差价、考虑货舱该装什么？Trade Route Planner 会根据你当前的资金、货舱、燃料、补给和时间限制，直接寻找收益较高的贸易路线，并告诉你每一站该买什么、卖什么。

实际使用很简单：

**计算新路线 → 导航到下一站 → 到站后自动买卖 → 继续下一站。**

规划器会综合市场价格、供需、关税、预计库存、舰队货舱和资金等因素计算路线，也支持开市（合法市场）和黑市。它不会修改市场价格或凭空生成商品，所有交易仍然通过 Starsector 原本的市场系统完成。

当前目标版本：**Starsector 0.98a-RC8**

## 主要功能

* 根据当前舰队情况自动寻找高收益贸易路线

* 支持多站闭环和开环路线

* 自动计算每次停靠该买卖哪些商品以及大致数量

* 同时考虑现金、剩余货舱、燃料、补给和路线时间

* 按大宗交易的实际报价计算，不简单使用“单价 × 数量”

* 可分别设置各势力是否允许使用开市和黑市

* 一键导航至下一站

* 到站后可自动完成计划中的买卖

* 在旅行地图左侧显示当前路线作业单

* 路线保存在当前存档中，读档后可继续执行

* 支持 Nexerelin 等拥有大量市场的模组环境

本模组与 Stelnet 一类市场信息模组并不冲突。Stelnet 更适合手动查询市场和商品信息，而 Trade Route Planner 负责直接根据你的舰队情况规划一条值得跑的路线。

## 安装

将 `TradeRoutePlanner` 文件夹放入：

`starsector/mods/`

启动游戏后，在启动器中勾选 **Trade Route Planner** 即可。

LunaLib 为可选依赖。安装 LunaLib 后，可以通过 **F2** 在游戏内修改路线时间、闭环、停靠站上限、燃料和补给保留量等设置；没有 LunaLib 时，也可以直接修改：

`data/config/settings.json`

## 使用方法

打开：

**情报 → 贸易活动 → 跑商规划器**

点击 **「计算新路线」**。

规划完成后，界面会显示预计贸易利润、预计天数、每个停靠市场，以及各站计划买入和卖出的商品。

`+买` 表示计划买入`-卖` 表示计划卖出。

点击 **「设导航（下一站）」** 即可把导航设置到当前下一站。抵达对应市场后，可以自己按照作业单交易，也可以直接点击 **「本站自动买卖」**，规划器会根据市场当时的实际库存尽可能完成这一站的交易。

完成后，作业单默认会自动切换到下一站，再次设置导航即可继续。

规划器只负责路线和交易计划，不会自动驾驶整条路线。

## 路线设置

默认搜索闭环路线，也就是最后回到路线的起点市场。例如：

`Jangala → Sindria → Kazeron → Jangala`

这里的终点是路线起点市场，而不是你点击「计算新路线」时舰队所在的太空位置。

关闭闭环后，也可以搜索不返回起点的开环路线。

第一站默认从距离当前舰队约 10 光年以内的市场中选择；与你处于同一星系的市场也会考虑。这个限制只影响第一站，后续路线可以前往更远的市场。

规划器还会考虑前往第一站所需的时间。游戏设置中的 **「定位权重 alpha」** 控制这一因素的影响：

* `0`：更看重路线本身的收益

* `0.5`：默认值，兼顾前往第一站的距离和之后的收益

* `1`：完整计入前往第一站的时间

普通情况下保持默认即可。

## 开市与黑市

在跑商规划器中打开 **「规划设置」**，可以分别决定各个势力是否允许使用开市或黑市。

两者都关闭时，规划器不会与该势力进行贸易。

两者都开启时，会优先考虑黑市；如果还有剩余货舱，并且通过开市继续交易仍然有利可图，也可能继续使用开市。

默认设置为：

* 海盗：仅黑市

* 卢德左径：仅黑市

* 其他势力：仅开市

修改后点击 **「确认」** 保存，并重新计算路线。

## 库存与交易数量

规划器无法在你尚未访问某个市场时直接知道当地贸易界面的真实库存，因此路线中的商品数量都是估算值。

对于远方市场，它会根据当地的生产、需求和稳定度等信息估算库存；如果你之前访问过该市场，则会参考上次看到的库存，并按照原版市场的补货速度估算当前恢复情况。

默认只按预计库存的 90% 参与规划，留出一定余量，减少到站后实际商品不足的问题。

真正执行「本站自动买卖」时，会以当前市场的实际库存为准。因此计划购买 800 单位商品，到站后如果只有 600，最终就只会购买实际能够成交的数量。

大批量交易时，规划器也会使用整批商品的实际报价，而不是拿一个单价直接乘数量。随着买入或卖出数量增加，价格会发生变化，规划器会根据变化后的收益判断继续交易是否划算。

## 货舱、资金和补给

每一段路线中，规划器都会根据当前现金和剩余货舱重新决定应该携带哪些商品，并尽量选择收益更高的组合。

燃料主要按照航行需求保留，不作为普通投机商品参与路线规划。

补给可以正常参与贸易，但不会主动卖到低于设置中的保留量。

规划器使用的是当前剩余货舱，因此你原本携带的其他商品也会占用可用于跑商的空间。

## 路线搜索

安装大量势力和殖民地模组后，整个星区可能存在非常多的市场，不可能把所有市场排列全部计算一遍。

规划器会先根据各地商品的过剩、短缺和距离筛出比较有希望的航段，再进一步计算具体交易和多站路线。

搜索本身有运行时间限制。达到时限后，会直接使用截至当时找到的最佳路线，避免长时间卡住游戏。

因此，计算结果代表的是规划器在当前搜索范围和时间内找到的较优路线，并不保证一定是整个星区数学意义上的绝对最优解。

## 关于预计利润和时间

规划结果会显示预计贸易利润以及预计贸易利润/天。

需要注意，目前这里显示的利润**不会扣除航行途中消耗的燃料和舰队每日消耗的补给成本**。规划器会检查燃料是否足够，并考虑燃料和补给保留量，但这些运营成本暂时不会直接从显示的利润中扣除。

因此，这个数字更适合用来比较不同贸易路线，而不是理解成最终一定增加这么多信用点的纯利润。

预计航行时间同样可能与实际情况存在偏差，因为实际游戏中的滑流、持续燃烧、超空间风暴、绕路以及市场在星系内的具体位置都会影响最终航程。

市场库存、短缺和价格也可能在你抵达之前发生变化，所以路线始终是一份根据当前信息计算出的计划，而不是对未来市场情况的保证。

## 默认设置

| 设置         |     默认值 |

| ---------- | ------: |

| 路线时间上限     |    30 天 |

| 闭环路线       |      开启 |

| 额外停靠站上限    |       4 |

| 第一站范围      |   10 光年 |

| 计算时限       | 2000 ms |

| 库存使用比例     |     90% |

| 补给保留       |   100 天 |

| 燃料保留       |   100 天 |

| 到站自动切换     |      开启 |

| 旅行地图作业单    |      开启 |

| 定位权重 alpha |     0.5 |

大型 Nexerelin 或多势力模组环境下，如果市场数量很多，可以适当增加计算时限；如果觉得计算过慢，也可以减少停靠站上限。
