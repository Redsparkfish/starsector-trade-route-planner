# Trade Route Planner 星区跑商智能规划器

**在时间预算里，帮你找出更值钱的那条回路。**

这是一份**咨询式**跑商规划，不是全自动跑商机器人。它读星区经济层的价格与关税，按你的现金、货舱、燃料和天数上限，估一条多停路线，并列出每一站该买什么、该卖什么。航行仍用游戏原版「设导航」；飞到之后，你可以自己开门成交，也可以点「本站自动买卖」按当场货架尽力成交。

- 估计 **净利/天**（利润 ÷ 全程预计天数，含飞到第一站）
- 分站作业单：绿 `+买`、红 `-卖`，数量标明是估计
- **设导航（下一站）** 只铺当前这一站，不连锁全程自动驾驶
- 到站后可选 **本站自动买卖**；作业单会写入存档

针对 Starsector **0.98a-RC8**（0.97a+ 一般也可运行）。

---

## 能做什么，不能做什么

| 能 | 不能 |
|----|------|
| 读非隐藏殖民地的经济价格、短缺/过剩、开市与黑市关税 | 远程看见商店货架上的真实件数 |
| 按货舱、现金、油、时间预算搜多停闭环或开环 | 一次点完就自动飞完全程 |
| 情报详情 + 旅行地图小地图左侧作业单 | 人还没到站就自动停靠成交 |
| 路线与下一站随存档保留，读档不用重算 | 保证横幅上的数字等于实际入账 |

规划器给的是**作业单**。飞行、停靠、成交仍走游戏本体规则。

## 安装

1. 把整个 `TradeRoutePlanner` 文件夹放到 `starsector/mods/`。
2. 确认模组目录里有 `jars/TradeRoutePlanner.jar`（没有则无法加载）。
3. 启动器勾选 **Trade Route Planner 星区跑商智能规划器**，读档即可。

**可选：** 安装 [LunaLib](https://fractalsoftworks.com/forum/index.php?topic=17923.0) 后，可在游戏内 **F2** 调时间预算、闭环、停数、保留天数等。没有 LunaLib 时，改模组里的 `data/config/settings.json`。

与 [Nexerelin](https://fractalsoftworks.com/forum/index.php?topic=12791.0) 兼容；星区很大时请把计算时限调高，或把最多停靠站调低，以免点计算时卡一下。本模组不做全市场价目表，需要比价情报可继续用 Stelnet。

## 使用方法

### 算出一条路线

读档后打开情报，分类 **贸易活动**，条目 **跑商规划器**，点 **计算新路线**。

横幅会给出预计净利、预计天数、净利/天。净利/天的分母是**全程**：从你现在的位置飞到第一站，再加上跑完回路（或开环）的时间。数量旁会写「估计」。

默认搜的是闭环：终点回到起点那座市场，**不会**飞回你点计算时舰队所在的太空位置。第一站默认只在约 **10 光年** 超空间范围内挑（同星系始终算进去）。

### 飞过去

点 **设导航（下一站）**。战役层会出现这一站的航线，之后按原版飞。点地图会取消航线，再点一次「设导航」即可。不会一次排完全程航点。

飞到（或停靠）下一站时，作业单默认会自动推进，并弹出战役消息。关掉「到站自动推进」后，只能在**情报大面板**点 **标记抵达**。旅行地图上的作业单**没有**这个按钮。

### 到站买卖

你可以按作业单自己开门成交，也可以点 **本站自动买卖**：

- 必须已经抵达当前下一站。没到只提示，舰队不会自己飞过去。
- 走原版停靠与交易界面，按**当场货架**尽力成交。实际件数往往少于计划，消息里会写计划 / 实际。
- 被巡逻队追踪、港务局拒绝交易、暗中停靠但本站规划是开市等情况会中止，并暂停说明原因。
- 不会连锁下一站，也不会自动开关应答器。

走完最后一站后，会按实际天数和现金变化给一行行程总结。

### 旅行地图作业单

战役旅行时，小地图**左侧**有一张紧凑卡：净利/天、下一站买卖、计算 / 导航 / 买卖 / 详情。可折叠。打开对话、菜单或情报/舰队等界面时会收起，避免挡点击。F2 可关掉整张卡。

「打开详情」会跳到情报大面板。全程分站卡片只在大面板里。

### 规划设置（当前存档）

情报大面板点 **规划设置**：

- 每个势力单独勾选 **开市** / **黑市**（两边都开则先黑市，仍有利再开市补仓；两边都关则不与该势力交易）
- **定位权重 alpha**：搜索时多在乎「飞到第一站」的时间（0 忽略定位，1 与跑圈同等）

勾选只改本页草稿。顶部 **确认** 写入存档并返回规划页，**取消** 丢草稿，**恢复默认** 只重置草稿（仍须确认）。改完请再点一次 **计算新路线**。

新存档默认：海盗、卢德左径仅黑市，其余仅开市。

## 算法原理

规划器要回答的是：在你设定的天数上限内，选几座殖民地、每跳装什么货，使

**净利 / 全程预计天数**

尽量高。这里的天数包括飞到第一站，再加上买卖回路（或开环）本身。

**货能买多少。** 游戏不会把远处商店的货架暴露给模组。没去过的店，按经济层的期望库存（与稳定度有关）再乘安全边际来估；去过的店，用上次开门剩下的货，再按原版节奏补货或回收。卖出没有件数硬顶，只看批量报价在滑价之后还赚不赚钱。开市非法品不能在开市卖。

**每一跳装什么。** 在货舱和现金限制下做有界背包：用「这一整笔」的买价/卖价，而不是单价乘数量。同一势力若开市、黑市都开，会先按黑市装舱，还有空再走开市。燃料占油箱，不当投机货；补给可以当大宗货跑，但不会卖到你设的保留天数以下。

**怎么选路。** 先在附近挑起点，再用廉价的过剩/缺口启发式筛一批有利航段，然后搜短环（默认最多再停 4 站）。有墙钟时限（默认约 2 秒）：星区很大时会停在当前最优，而不是把游戏卡死。搜索排序还会用 alpha（默认 0.5）打折「飞到第一站」的时间，所以搜出来的「最优」不一定等于横幅上最高的净利/天；把 alpha 调到 **1** 则两者一致。

油够不够飞、途中要不要补油仍会检查。超空间油费和日补给折成信用点的成本，**目前不从净利里扣除**。

## 设置一览

游戏内 **F2**（需 LunaLib）或 `data/config/settings.json`：

| 项 | 默认 | 说明 |
|----|------|------|
| 时间预算 | 30 天 | 全程预计旅行时间上限，不是市场营业时间 |
| 闭环路线 | 开 | 终点回到起点市场，不返回计算时的舰队位置 |
| 最多停靠站 | 4 | 不含起点；大图可调低 |
| 起点范围 | 10 光年 | 只限制第一站；中途站可以更远 |
| 计算时限 | 2000 毫秒 | 超时返回当前最优 |
| 数量安全边际 | 0.9 | 乘在期望货架或 leftover 上 |
| 补给 / 燃料保留 | 各 100 天 | 0 为不保留；燃料按当前 burn 的超空间日耗折算 |
| 到站自动推进 | 开 | 关则只能在情报里点「标记抵达」 |
| 旅行地图作业单 | 开 | 关则只能从情报进入 |
| 定位权重 alpha | 0.5 | 也可在情报「规划设置」里按存档改 |

## 注意事项

- **估计不是保证。** 货架无法远程精确读取；你成交后，当地价格和可供量会变，后面几站的计划数字可能对不上。请把作业单当指南，到店再看实际货架。
- **天数为预计。** 不含滑流、持续燃烧、超空间风暴或行星轨道相位。实际航程往往和横幅有出入。
- **关税。** 开市默认买卖双边约 30%；黑市为 0。敌对殖民地走开放市场通常要开着应答器停靠；关应答器暗中停靠时，开市往往不可用。
- **现有货物。** 规划按剩余货舱来买，不会先帮你卖掉舱里已经装着的货。
- **军事市场、声望过滤** 尚未做进搜索。作业单也不会因为敌对/应答器状态再单独弹一条警告。
- **追踪与战斗。** 被巡逻队追踪时自动买卖不会成交。战斗或打开菜单会中止正在进行的自动买卖。
- 关掉「到站自动推进」后，HUD 上没有「标记抵达」，请打开情报详情手动点。
